# 安隅 (Anyu) - 官方网站

这是“隅安 (Anyu)”APP 的官方网站及隐私政策托管仓库。基于 [VitePress](https://vitepress.dev/) 构建。

## 🌐 网站内容

- **首页**: APP 核心功能介绍。
- **隐私政策**: 符合 App Store 上架要求的隐私协议说明。
- **关于我们**: 开发者信息。

## 🛠 本地开发

在使用之前，请确保您的 Node.js 版本 >= 18.0.0。

```bash
# 安装依赖
npm install

# 启动本地开发服务器 (默认端口 5173)
npm run dev

# 构建生产环境静态文件
npm run build

#本地预览构建后的产物
npm run preview
```

## 🚀 部署说明

项目已配置 GitHub Actions。当代码推送到 `main` 分支后，会自动构建并部署到 GitHub Pages。
